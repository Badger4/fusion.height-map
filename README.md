# Heightmap to MeshBody — Fusion 360

Скрипт для Fusion 360, який перетворює звичайне зображення (карту висот у відтінках сірого) на 3D-рельєф у вигляді `MeshBody`, з жорсткою математичною прив'язкою яскравості пікселя до координати Z у міліметрах.

## Що це робить

- Береш будь-яке зображення (фото, скан, згенеровану карту висот).
- Обираєш форму заготовки прямо в діалозі: **прямокутник**, **коло** або **багатокутник**.
- Скрипт будує сітку вершин за прямою пропорцією:

  ```
  Z = (Значення_пікселя / 255) * Глибина_рельєфу
  ```

  Чорний піксель (0) → Z = 0. Білий піксель (255) → Z = задана максимальна глибина. Ніякої непередбачуваної товщини моделі.

- Результат обрізається точно по контуру обраної форми (коло — не квадрат з круглим рельєфом всередині, а справжній круглий контур мешу).
- Опційно добудовується суцільна "заготовка" знизу — товщина матеріалу під рельєфом, зі стінками по контуру, згенерованими геометрично (працює однаково для будь-якої форми).
- Все вставляється як `MeshBody` через підтверджений виклик Fusion API `rootComp.meshBodies.add(...)`, а не через побудову BRep-тіла — тому ядро не "задихається" навіть на великих сітках.


## Вимоги

- Autodesk Fusion 360 (десктопна версія зі Scripts and Add-Ins).
- Документ у **параметричному режимі** — тобто увімкнено "Capture design history" (значок вгорі полотна). Без цього вставка мешу через `BaseFeature` неможлива в принципі — так влаштований сам Fusion API.
- Бібліотека **Pillow (PIL)**, встановлена саме в Python-середовищі Fusion 360, а не в системному Python.

### Встановлення Pillow

**Windows:**
```
"C:\Users\<User>\AppData\Local\Autodesk\webdeploy\production\<hash>\Python\python.exe" -m pip install Pillow
```

**macOS:**
```
/Users/<User>/Library/Application\ Support/Autodesk/webdeploy/production/<hash>/Python.framework/Versions/Current/bin/python3 -m pip install Pillow
```

`<hash>` — це унікальна тека твоєї інсталяції Fusion, знайди її вручну в цій директорії.

## Встановлення скрипта

1. Завантаж `heightmap_to_mesh.py` з цього репозиторію.
2. У Fusion 360: **Utilities → Scripts and Add-Ins → вкладка Scripts → "+" (Add)**.
3. Вкажи завантажений файл.
4. Обери його зі списку та натисни **Run**.

## Використання

1. Після запуску з'явиться кнопка на панелі **SOLID → CREATE**, і одразу відкриється діалог.
2. **Файл зображення** — натисни "Обрати зображення..." і вибери карту висот (PNG/JPG/BMP/TIFF).
3. **Форма заготовки** — обери з випадаючого списку:
   - *Прямокутник* — вкажи Ширину (X) і Довжину (Y).
   - *Коло* — вкажи Діаметр.
   - *Багатокутник* — вкажи Кількість граней (3–24) і Радіус до вершини.
4. **Глибина рельєфу** — на скільки міліметрів підніметься найсвітліший піксель (255) над найтемнішим.
5. **Висота заготовки** — товщина суцільного матеріалу під рельєфом. `0` = без дна (лише відкрита рельєфна поверхня, без стінок). Будь-яке значення > 0 → автоматично добудовуються дно і стінки по контуру.
6. **Крок сітки** — відстань між сусідніми вершинами в мм. Менше значення = вища деталізація, але важча сітка і довший розрахунок.
7. **Проходи згладжування** — кількість проходів усереднення 3×3 по висотах сусідніх вершин, прибирає піксельні "голки" ще до побудови моделі.
8. Натисни **OK** — скрипт побудує сітку і вставить готовий `MeshBody` у документ.

## Параметри в двох словах

| Параметр | Що означає |
|---|---|
| Глибина рельєфу | 255 → ця висота, 0 → нуль |
| Висота заготовки | товщина "підкладки" під рельєфом |
| Крок сітки | деталізація (мм між вершинами) |
| Проходи згладжування | усереднення сусідніх висот, прибирає шум |

Загальна фізична висота готової моделі = **Висота заготовки + Глибина рельєфу**.

## Обмеження і поради

- Дуже велике зображення при малому кроці сітки дасть мільйони вершин — скрипт попередить, якщо сітка перевищує ~400 000 вершин, і дасть скасувати або продовжити.
- Для складних несамопересічних форм (не тільки правильний багатокутник) можна легко розширити функцію `mask_fn` — вона просто приймає (x, y) в мм і повертає True/False.
- Скрипт пише тимчасовий `.obj` файл у системну теку temp і видаляє його одразу після імпорту.
